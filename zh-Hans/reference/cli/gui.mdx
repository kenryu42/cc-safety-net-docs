`gui` 启动本地策略编辑器，并在浏览器中打开它。服务器会一直运行，直到你按 `Ctrl-C` 停止。

```bash
npx cc-safety-net gui
npx cc-safety-net gui --no-open
```

编辑器的各个视图见[仪表板](/zh-Hans/guides/dashboard)；谁能访问服务器、每次运行生成的令牌，见[本地环回范围](/zh-Hans/guides/dashboard#local-loopback-scope)。

## gui 选项

| 选项 | 描述 |
| --- | --- |
| `--no-open` | 启动服务器并打印 URL，但不启动浏览器 |
| `-h`, `--help` | 显示帮助 |

其他任何参数都会打印一条错误和 `Usage: cc-safety-net gui [--no-open]`，然后退出 `1`。

## gui 启动与浏览器打开

无论是否带 `--no-open`，`gui` 都会启动服务器并打印 `CC Safety Net policy GUI: <url>`。浏览器打开失败时，服务器照常运行，你自己打开打印出的 URL 即可。
