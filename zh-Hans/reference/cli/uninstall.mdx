`uninstall` 从编码智能体 CLI 中移除 CC Safety Net。它只移除 CC Safety Net 管理的内容，其他一切原样保留。

```bash
npx -y cc-safety-net uninstall
npx -y cc-safety-net uninstall --cursor
```

## uninstall 目标与选择

`uninstall` 接受与 `install` 相同的十六个目标选项，选择规则也相同。参见 [install 目标选项](/zh-Hans/reference/cli/install#install-target-flags)和[选择目标](/zh-Hans/reference/cli/install#selecting-a-target)。

各智能体的页面列出了卸载会移除的内容，可以从[安装](/zh-Hans/installation#install-for-one-agent)页面的表格开始查找。

## uninstall 从配置文件中移除的内容

对于在智能体配置文件中写入 hook 条目的目标，`uninstall` 只移除 CC Safety Net 的条目，文件的其余部分保持不变。

## 在 Cursor 中运行 uninstall

存在原生 Cursor 插件时，`uninstall --cursor` 还会从你的 Cursor 账户中移除 cc-safety-net 市场。参见[从 Cursor 卸载 CC Safety Net](/zh-Hans/installation/cursor#uninstall-cc-safety-net-from-cursor)。
