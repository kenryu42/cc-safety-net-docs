运行 `npx -y cc-safety-net@latest install`，然后从列表中选择你的编码智能体。安装程序会以插件、扩展或 hook 的形式，把 CC Safety Net 添加到你选中的每个智能体中。部分智能体随后需要重启或确认信任。运行 `npx cc-safety-net doctor` 确认保护已生效。

<span id="before-you-install"></span>

## 安装前须知

- 安装 Node.js 18 或更高版本。本页的命令都使用 `npx`。
- 确认你的智能体在当前平台上受支持：

| 平台 | 智能体 |
| --- | --- |
| Windows、macOS 和 Linux | 除下列以外的所有智能体 |
| 仅 macOS 和 Linux | [Hermes Agent](/zh-Hans/installation/hermes-agent)、[OpenClaw](/zh-Hans/installation/openclaw) |
| web profile 支持全部三个平台，桌面应用支持 macOS 和 Windows | [DeepSeek Harness](/zh-Hans/installation/deepseek-harness) |

Amp 官方手册只列出 macOS、Linux 和 WSL，不包括原生 Windows。

## 使用交互式选择器安装

<Steps>
  <Step title="启动安装程序">
    ```bash
    npx -y cc-safety-net@latest install
    ```

    安装程序会列出它在你机器上找到的编码智能体。
  </Step>
  <Step title="选择智能体">
    按 `Space` 选择智能体，按 `Enter` 确认。其他按键见[目标选择器按键](/zh-Hans/reference/cli/install#target-selector-keys)。
  </Step>
  <Step title="完成智能体自身的步骤">
    如果你的智能体需要重启或确认信任后 hook 才会运行，现在就完成这一步。[为单个智能体安装](#install-for-one-agent)中的“额外步骤”一列列出了这些步骤。
  </Step>
  <Step title="确认保护已生效">
    ```bash
    npx cc-safety-net doctor
    ```
  </Step>
</Steps>

[`doctor`](/zh-Hans/reference/cli/doctor) 会检查每个受支持的智能体，并告诉你如何修复失败的项目。

安装命令中请保留 `@latest`。npx 会把下载的软件包保存在缓存中，不带版本的 `cc-safety-net` 可能会从缓存中重新运行旧副本，而不是当前发布版本。

## 为单个智能体安装

只为一个智能体安装时（例如在脚本中），请传入下表中该智能体的目标选项。每个智能体的页面会说明安装改动了什么、该智能体的 hook 检查什么，以及如何卸载。

| 智能体 | 安装命令 | 额外步骤 |
| --- | --- | --- |
| [Amp Code](/zh-Hans/installation/amp-code) | `npx -y cc-safety-net@latest install --amp` | 重启 Amp 或运行 `plugins: reload` |
| [Antigravity CLI](/zh-Hans/installation/antigravity-cli) | `npx -y cc-safety-net@latest install --agy-cli` | |
| [Claude Code](/zh-Hans/installation/claude-code) | `npx -y cc-safety-net@latest install --claude-code` | |
| [Codex](/zh-Hans/installation/codex) | `npx -y cc-safety-net@latest install --codex` | 在 `/hooks` 中信任该 hook |
| [Cursor](/zh-Hans/installation/cursor) | `npx -y cc-safety-net@latest install --cursor` | |
| [DeepSeek Harness](/zh-Hans/installation/deepseek-harness) | `npx -y cc-safety-net@latest install --deepseek-harness` | 安装前退出桌面应用 |
| [Devin CLI](/zh-Hans/installation/devin-cli) | `npx -y cc-safety-net@latest install --devin` | |
| [Factory Droid](/zh-Hans/installation/factory-droid) | `npx -y cc-safety-net@latest install --droid` | |
| [Gemini CLI](/zh-Hans/installation/gemini-cli) | `npx -y cc-safety-net@latest install --gemini-cli` | 重启 Gemini CLI |
| [GitHub Copilot CLI](/zh-Hans/installation/github-copilot-cli) | `npx -y cc-safety-net@latest install --copilot-cli` | 重启 Copilot CLI |
| [Grok Build](/zh-Hans/installation/grok-build) | `npx -y cc-safety-net@latest install --grok-build` | |
| [Hermes Agent](/zh-Hans/installation/hermes-agent) | `npx -y cc-safety-net@latest install --hermes-agent` | 重启 Hermes |
| [Kimi Code](/zh-Hans/installation/kimi-code) | `npx -y cc-safety-net@latest install --kimi-code` | 选择全局 hook 或原生插件 |
| [OpenClaw](/zh-Hans/installation/openclaw) | `npx -y cc-safety-net@latest install --openclaw` | 重启 OpenClaw Gateway |
| [OpenCode](/zh-Hans/installation/opencode) | `npx -y cc-safety-net@latest install --opencode` | 重启 OpenCode |
| [Pi](/zh-Hans/installation/pi) | `npx -y cc-safety-net@latest install --pi` | 重启 Pi |

安装命令可以放心重复运行。对已配置的智能体再次运行，最终只会保留一个托管条目。

## 更新 CC Safety Net

```bash
npx -y cc-safety-net@latest update
```

`update` 会刷新你机器上已安装的所有集成，但从不安装新的集成。它对每个智能体做了什么，见 [`update`](/zh-Hans/reference/cli/update)。

### 从 v1 或 2.2 及更早版本升级

- **从 v1 升级。** 运行 `update`，把每个已安装的集成迁移到当前版本。如果你在 v1 的内联配置中定义了自定义规则，请完成[旧配置迁移](/zh-Hans/configuration/custom-rules#migrate-legacy-configuration)。然后运行 `npx cc-safety-net doctor`，确认运行时为 `ready`。
- **从 2.2 或更早版本升级，且使用了来自 GitHub 的 rulebook。** 升级后，按范围各运行一次 [`rule sync`](/zh-Hans/reference/cli/rule#rule-sync)，用户范围的来源需加上 `--global`。运行之前，这些规则不会生效，`status` 和 `doctor` 会把相应来源报告为 degraded。

## 卸载 CC Safety Net

运行安装程序的卸载选择器，或传入一个目标选项：

```bash
npx -y cc-safety-net@latest uninstall
npx -y cc-safety-net@latest uninstall --cursor
```

卸载只删除 CC Safety Net 自己管理的内容。每个智能体的页面都列出了卸载会删除什么。

## 全局安装 CLI

如果你经常使用 CLI，可以全局安装。全局安装会附带 `ccsn`，它是同一组命令的短别名：

```bash
npm install -g cc-safety-net
ccsn doctor
```

该别名只随全局安装提供。通过 `npx` 运行时，仍使用完整的 `cc-safety-net` 名称。

<span id="migrate-from-a-legacy-plugin-identifier"></span>

## 从旧插件标识符迁移

早期版本中，Claude Code 和 Codex 使用的插件标识符是 `safety-net@cc-marketplace`，GitHub Copilot CLI 使用的是 `copilot-safety-net`。运行对应智能体的常规安装命令就会删除旧插件，无需手动删除。新配置请使用当前标识符 `cc-safety-net@cc-marketplace`。
