    <div className="cc-overview-lede">
      <p>
        Stop your coding agent from running <code>git reset --hard</code>, <code>rm -rf ~/</code>, or <code>cat .env</code>. CC Safety Net checks every command before it runs and blocks the ones that destroy work or expose secrets.
      </p>

  <section className="cc-overview-release" aria-label="Latest release">
    <div className="cc-release-head">
      <h2>What's new in v2.7.0</h2>
      <span className="cc-release-date">Released October 27, 2026</span>
    </div>
    <ul>
      <li>Blocks requests to cloud metadata endpoints, <code>curl</code> and <code>wget</code> uploads to a remote host, and <code>unshare</code> user namespaces. Uploads block even when the file holds no secrets, such as <code>curl -F file=@notes.txt</code>. See <a href="/reference/blocked-commands#network-commands">Network commands</a>.</li>
      <li>Reads the shell script a command runs from disk, so a destructive command saved in <code>evil.sh</code> and run as <code>sh evil.sh</code> is blocked. See <a href="/reference/blocked-commands#scripts-run-from-a-file">Scripts run from a file</a>.</li>
    </ul>
    <p className="cc-release-breaking"><strong>Breaking change:</strong> CC Safety Net now needs Node.js 22 or later. See <a href="/installation#before-you-install">Before you install</a>.</p>
    <p>Update every installed integration with <code>npx -y cc-safety-net@latest update</code>. <a href="https://ccsafetynet.com/release#release-v2.7.0">Read the full release notes</a>.</p>
  </section>
