`gui` は、ローカルのポリシーエディターを起動し、ブラウザーで開きます。サーバーは `Ctrl-C` で停止するまで動作し続けます。

```bash
npx cc-safety-net gui
npx cc-safety-net gui --no-open
```

エディターのビューは[ダッシュボード](/ja/guides/dashboard)を、サーバーに接続できる範囲と実行ごとのトークンは[ローカルループバックに限定されている](/ja/guides/dashboard#local-loopback-scope)を参照してください。

## gui のオプション

| フラグ | 説明 |
| --- | --- |
| `--no-open` | ブラウザーを起動せずにサーバーを起動し、URL を出力する |
| `-h`, `--help` | ヘルプを表示する |

ほかの引数を指定すると、エラーと `Usage: cc-safety-net gui [--no-open]` を出力して `1` で終了します。

## gui の起動とブラウザーの起動

`gui` はサーバーを起動し、`--no-open` の有無に関係なく `CC Safety Net policy GUI: <url>` を出力します。ブラウザーを開けなかった場合もサーバーは動作を続けるので、出力された URL を自分で開いてください。
