`cc-safety-net` は、CC Safety Net が提供する唯一の CLI です。コーディングエージェントへの CC Safety Net のインストール、適用中の内容の確認、ルールとポリシーの管理に使います。

```bash
npx cc-safety-net <command>
bunx cc-safety-net <command>
```

`npx` または `bunx` が実行時に CLI を取得するため、グローバルにインストールする必要はありません。初回実行の手順は[クイックスタート](/ja/quickstart)、エージェントごとの設定は[インストール](/ja/installation)を参照してください。

## cc-safety-net のコマンド一覧

CLI には 12 個のコマンドがあります。次の表は、`cc-safety-net --help` に表示される順に並べています。

| コマンド | 使用方法 | 動作 |
| --- | --- | --- |
| [`status`](/ja/reference/cli/status) | `status` | ランタイムが現在適用している内容を表示する |
| [`doctor`](/ja/reference/cli/doctor) | `doctor [options]` | インストールと設定に問題がないかを検査する |
| [`logs`](/ja/reference/cli/logs) | `logs [options]` | フックが記録した監査ログエントリを表示する |
| [`explain`](/ja/reference/cli/explain) | `explain [options] <command>` | CC Safety Net がコマンドを解析する過程を手順ごとに表示する |
| [`rule`](/ja/reference/cli/rule) | `rule <subcommand>` | ルール設定、ルールブックの設定元、透過ラッパー、宣言済みのコマンド用ツールを管理する |
| [`policy`](/ja/reference/cli/policy) | `policy <subcommand>` | プロジェクトまたはユーザーのポリシー提案を検査して適用する |
| [`install`](/ja/reference/cli/install) | `install [TARGET_FLAG]` | CC Safety Net をコーディングエージェント CLI にインストールする |
| [`update`](/ja/reference/cli/update) | `update` | インストール済みのすべての連携をその場で更新する |
| [`uninstall`](/ja/reference/cli/uninstall) | `uninstall [TARGET_FLAG]` | CC Safety Net をコーディングエージェント CLI から削除する |
| [`hook`](/ja/reference/cli/hook) | `hook INTEGRATION_FLAG` | エージェントのランタイムフックとして動作し、標準入力から JSON を読み取る |
| [`gui`](/ja/reference/cli/gui) | `gui [options]` | ローカルのポリシーエディター GUI を開く |
| [`statusline`](/ja/reference/cli/statusline) | `statusline --claude-code` | シェル連携用の 1 行ステータスインジケーターを出力する |

`doctor` は別名 `--doctor` でも実行できます。コマンド名の大文字と小文字は区別しません。

## cc-safety-net のグローバルオプション

`--version` はインストール済みのバージョンを出力します。短縮形は `-V` です。`--help` は使用方法を出力します。短縮形は `-h` です。

特定のコマンドの使用方法を表示するには、`help <command>` または `<command> --help` を実行します。

```bash
npx cc-safety-net help explain
npx cc-safety-net explain --help
```

## 不明なコマンドのエラー

CLI が認識しないコマンドを指定すると、`Unknown command: <name>` を出力して `1` で終了します。名前が `-` で始まる場合は、代わりに `Unknown option: <name>` を出力します。
