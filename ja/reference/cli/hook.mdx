`hook` は、エージェントがツールを実行する前に呼び出すコマンドです。エージェントのフック入力を標準入力から JSON として読み取り、呼び出しをブロックする場合はそのエージェントの拒否形式で応答します。設定はエージェントのプラグインや設定ファイルが行うため、通常は手で実行しません。

たとえば `install --cursor` は、次のコマンドを Cursor のフック設定に書き込みます。Cursor はツールを呼び出すたびにこのコマンドを実行します。

```bash
npx -y cc-safety-net hook --cursor
```

## hook の連携フラグ

`hook` には、エージェントを示す連携フラグを 1 つだけ指定する必要があります。フラグがない場合や複数ある場合は、`hook requires exactly one integration flag. Try: cc-safety-net hook --kimi-code` とコマンドのヘルプを表示し、`1` で終了します。

| フラグ | エージェント | レガシーフラグ |
| --- | --- | --- |
| `-ac`, `--agy-cli` | [Antigravity CLI](/ja/installation/antigravity-cli) | なし |
| `-cc`, `--coding-cli` | [Coding CLI（Claude Code）](/ja/installation/claude-code) | `--claude-code`。最上位形式の `cc-safety-net -cc` と `cc-safety-net --claude-code` も使える |
| `-cx`, `--codex` | [Codex](/ja/installation/codex) | なし |
| `-cu`, `--cursor` | [Cursor](/ja/installation/cursor) | なし |
| `-dv`, `--devin` | [Devin CLI](/ja/installation/devin-cli) | なし |
| `-fd`, `--droid` | [Factory Droid](/ja/installation/factory-droid) | なし |
| `-gc`, `--gemini-cli` | [Gemini CLI](/ja/installation/gemini-cli) | 最上位形式の `cc-safety-net -gc` と `cc-safety-net --gemini-cli` |
| `-cp`, `--copilot-cli` | [GitHub Copilot CLI](/ja/installation/github-copilot-cli) | 最上位形式の `cc-safety-net -cp` と `cc-safety-net --copilot-cli` |
| `-gb`, `--grok-build` | [Grok Build](/ja/installation/grok-build) | なし |
| `-ha`, `--hermes-agent` | [Hermes Agent](/ja/installation/hermes-agent) | なし |
| `-kc`, `--kimi-code` | [Kimi Code](/ja/installation/kimi-code) | なし |

フックが何を検査し、検査に失敗したときにどうなるかは、各エージェントのページで説明しています。Claude Code では、フックがブロックする代わりにユーザーに確認を求めることがあります。[Claude Code がブロックせずに確認を求める場合](/ja/installation/claude-code#when-claude-code-asks-you-instead-of-blocking)を参照してください。

## hook フラグのないエージェント

Amp Code、DeepSeek Harness、OpenClaw、OpenCode、Pi には `hook` のフラグがありません。これらは、CC Safety Net をプラグインまたは拡張機能として自身のプロセス内に読み込みます。[連携方式](/ja/guides/how-it-works#integration-models)を参照してください。

<Note>
  `hook install` や `hook uninstall` というサブコマンドはありません。最上位の [`install`](/ja/reference/cli/install) と [`uninstall`](/ja/reference/cli/uninstall) コマンドを使ってください。
</Note>
