`uninstall` は、コーディングエージェント CLI から CC Safety Net を削除します。削除するのは CC Safety Net が管理するものだけで、それ以外はそのまま残します。

```bash
npx -y cc-safety-net uninstall
npx -y cc-safety-net uninstall --cursor
```

## uninstall のターゲットと選択

`uninstall` は、`install` と同じ 16 個のターゲットフラグと選択ルールを使います。[install のターゲットフラグ](/ja/reference/cli/install#install-target-flags)と[ターゲットの選択](/ja/reference/cli/install#selecting-a-target)を参照してください。

アンインストールで削除される内容は、各エージェントのページに記載しています。[インストール](/ja/installation#install-for-one-agent)の表から各ページを開いてください。

## uninstall が設定ファイルから削除するもの

エージェントの設定ファイルにフックのエントリをインストールするターゲットでは、`uninstall` は CC Safety Net のエントリだけを削除し、ファイルのほかの部分には触れません。

## Cursor での uninstall

ネイティブ Cursor プラグインがある場合、`uninstall --cursor` は Cursor アカウントから cc-safety-net マーケットプレイスも削除します。[Cursor から CC Safety Net をアンインストールする](/ja/installation/cursor#uninstall-cc-safety-net-from-cursor)を参照してください。
