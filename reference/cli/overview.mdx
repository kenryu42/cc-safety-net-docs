`cc-safety-net` is the one CLI that CC Safety Net ships. You use it to install CC Safety Net into your coding agents, check what it enforces, and manage its rules and policy.

```bash
npx cc-safety-net <command>
bunx cc-safety-net <command>
```

It needs no global installation, because `npx` or `bunx` fetches it on demand. See the [Quickstart](/quickstart) for a guided first run and [Installation](/installation) for per-agent setup.

## cc-safety-net command list

The CLI has twelve commands. This table lists them in the order they appear in `cc-safety-net --help`.

| Command | Usage | What it does |
| --- | --- | --- |
| [`status`](/reference/cli/status) | `status` | Show what the runtime is enforcing right now |
| [`doctor`](/reference/cli/doctor) | `doctor [options]` | Check your installation and configuration for problems |
| [`logs`](/reference/cli/logs) | `logs [options]` | Browse the audit log entries that the hooks record |
| [`explain`](/reference/cli/explain) | `explain [options] <command>` | Show step by step how CC Safety Net analyzes a command |
| [`rule`](/reference/cli/rule) | `rule <subcommand>` | Manage rule config, rulebook sources, transparent wrappers, and declared command tools |
| [`policy`](/reference/cli/policy) | `policy <subcommand>` | Check and apply project or user policy proposals |
| [`install`](/reference/cli/install) | `install [TARGET_FLAG]` | Install CC Safety Net into a coding agent CLI |
| [`update`](/reference/cli/update) | `update` | Update every installed integration in place |
| [`uninstall`](/reference/cli/uninstall) | `uninstall [TARGET_FLAG]` | Remove CC Safety Net from a coding agent CLI |
| [`hook`](/reference/cli/hook) | `hook INTEGRATION_FLAG` | Run as an agent's runtime hook, reading JSON from stdin |
| [`gui`](/reference/cli/gui) | `gui [options]` | Open the local policy editor GUI |
| [`statusline`](/reference/cli/statusline) | `statusline --claude-code` | Print a one-line status indicator for shell integration |

`doctor` also answers to the alias `--doctor`. Command names are case-insensitive.

## cc-safety-net global options

`--version` prints the installed version. Its short alias is `-V`. `--help` prints usage. Its short alias is `-h`.

To see usage for one command, run `help <command>` or `<command> --help`:

```bash
npx cc-safety-net help explain
npx cc-safety-net explain --help
```

## Unknown command errors

A command the CLI does not recognize prints `Unknown command: <name>` and exits `1`. A name that starts with `-` prints `Unknown option: <name>` instead.
