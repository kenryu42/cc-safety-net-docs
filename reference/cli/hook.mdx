`hook` is the command your agent calls before it runs a tool. It reads the agent's hook input as JSON from stdin and, to block the call, answers in that agent's deny format. Your agent's plugin or config sets it up, so you do not normally run it by hand.

For example, `install --cursor` writes this command into Cursor's hook config, and Cursor runs it for every tool call:

```bash
npx -y cc-safety-net hook --cursor
```

## hook integration flags

`hook` requires exactly one integration flag, which names the agent. With no flag or more than one, it prints `hook requires exactly one integration flag. Try: cc-safety-net hook --kimi-code`, shows the command help, and exits `1`.

| Flag | Agent | Legacy flags |
| --- | --- | --- |
| `-ac`, `--agy-cli` | [Antigravity CLI](/installation/antigravity-cli) | None |
| `-cc`, `--coding-cli` | [Coding CLI (Claude Code)](/installation/claude-code) | `--claude-code`; also `cc-safety-net -cc` and `cc-safety-net --claude-code` as top-level forms |
| `-cx`, `--codex` | [Codex](/installation/codex) | None |
| `-cu`, `--cursor` | [Cursor](/installation/cursor) | None |
| `-dv`, `--devin` | [Devin CLI](/installation/devin-cli) | None |
| `-fd`, `--droid` | [Factory Droid](/installation/factory-droid) | None |
| `-gc`, `--gemini-cli` | [Gemini CLI](/installation/gemini-cli) | `cc-safety-net -gc` and `cc-safety-net --gemini-cli` as top-level forms |
| `-cp`, `--copilot-cli` | [GitHub Copilot CLI](/installation/github-copilot-cli) | `cc-safety-net -cp` and `cc-safety-net --copilot-cli` as top-level forms |
| `-gb`, `--grok-build` | [Grok Build](/installation/grok-build) | None |
| `-ha`, `--hermes-agent` | [Hermes Agent](/installation/hermes-agent) | None |
| `-kc`, `--kimi-code` | [Kimi Code](/installation/kimi-code) | None |

Each agent's page describes what its hook checks and what happens when the check fails. In Claude Code, the hook can ask you instead of blocking. See [When Claude Code asks you instead of blocking](/installation/claude-code#when-claude-code-asks-you-instead-of-blocking).

## Agents without a hook flag

Amp Code, DeepSeek Harness, OpenClaw, OpenCode, and Pi have no `hook` flag. They load CC Safety Net inside their own process, as a plugin or extension. See [Integration models](/guides/how-it-works#integration-models).

<Note>
  There is no `hook install` or `hook uninstall` subcommand. Use the top-level [`install`](/reference/cli/install) and [`uninstall`](/reference/cli/uninstall) commands.
</Note>
