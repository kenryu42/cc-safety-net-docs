`gui` starts the local policy editor and opens it in your browser. The server runs until you stop it with `Ctrl-C`.

```bash
npx cc-safety-net gui
npx cc-safety-net gui --no-open
```

See [Dashboard](/guides/dashboard) for the editor's views, and [Local loopback scope](/guides/dashboard#local-loopback-scope) for who can reach the server and its per-run token.

## gui options

| Flag | Description |
| --- | --- |
| `--no-open` | Start the server and print the URL without launching a browser |
| `-h`, `--help` | Show help |

Any other argument prints an error and `Usage: cc-safety-net gui [--no-open]`, then exits `1`.

## gui startup and browser launch

`gui` starts the server and prints `CC Safety Net policy GUI: <url>`, with or without `--no-open`. If the browser fails to open, the server keeps running and you open the printed URL yourself.
