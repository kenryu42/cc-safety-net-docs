`uninstall` removes CC Safety Net from a coding agent CLI. It removes only what CC Safety Net manages and leaves everything else in place.

```bash
npx -y cc-safety-net uninstall
npx -y cc-safety-net uninstall --cursor
```

## uninstall targets and selection

`uninstall` accepts the same sixteen target flags and selection rules as `install`. See [install target flags](/reference/cli/install#install-target-flags) and [Selecting a target](/reference/cli/install#selecting-a-target).

Each agent's page lists what its uninstall removes. Start from the [Installation](/installation#install-for-one-agent) table.

## What uninstall removes from config files

For targets that install a hook entry in the agent's config file, `uninstall` removes only the CC Safety Net entries and leaves the rest of the file untouched.

## uninstall in Cursor

When a native Cursor plugin is present, `uninstall --cursor` also removes the cc-safety-net marketplace from your Cursor account. See [Uninstall CC Safety Net from Cursor](/installation/cursor#uninstall-cc-safety-net-from-cursor).
