## What is CC Safety Net?

CC Safety Net is a pre-execution hook for AI coding agents like Claude Code, Codex, and Cursor. It checks each command and file operation before it runs and blocks the ones that destroy uncommitted work or expose secrets, such as `git reset --hard`, `git push --force`, `rm -rf` on your home directory, and reads of `.env` files, SSH keys, and cloud credentials. It supports 16 coding agents.

## Why it exists

As of October 2026, no major coding CLI deterministically blocks destructive git commands inside the workspace you handed it. `git reset --hard`, `git checkout -- .`, `git clean -f`, `git stash clear`, and `git push --force` act on files the agent may already write, so a sandbox that scopes writes to the project sees nothing wrong. OpenAI's [Codex security docs](https://learn.chatgpt.com/docs/security) say commands under workspace-write "can still mutate state and perform destructive operations". Claude Code's [sandboxing docs](https://code.claude.com/docs/en/sandboxing) scope writes to the working directory, which is where your uncommitted work lives.

Three more reasons to run it:

- **A deterministic check under probabilistic ones.** As of October 2026, Anthropic publishes a 17% false-negative rate for the Claude Code [auto-mode](https://www.anthropic.com/engineering/claude-code-auto-mode) classifier on real overeager actions and calls it "not a drop-in replacement for careful human review". A hook applies fixed rules instead of a judgment call.
- **Secret protection with nothing to configure.** Claude Code has no built-in credential deny list, and other CLIs make you write one per tool. CC Safety Net blocks `.env` files, SSH keys, and cloud credentials as soon as you install it. See [Secret protection](/reference/secret-protection).
- **One policy and one audit trail across 16 CLIs.** Five vendors ship five incompatible permission mechanisms and no decision log you can read afterwards.

Instructions in `CLAUDE.md` or `AGENTS.md` guide an agent but cannot enforce a limit. An agent once [wiped hours of work](https://www.reddit.com/r/ClaudeAI/comments/1pgxckk/claude_cli_deleted_my_entire_home_directory_wiped/) with one `rm -rf ~/` despite them. Adversa's [incident tracker](https://adversa.ai/blog/ai-coding-agent-incidents) records nine agent destruction cases from 2025 and 2026, with guardrails enabled in about half. The [protection-layers comparison](/guides/vs-sandboxing) covers the sandbox and allowlist CVEs.

## What it intercepts

CC Safety Net installs into your coding agent. It runs before the agent's tool call reaches your machine.

It inspects shell commands and file write, edit, search, and patch operations. It then allows the operation or blocks it with a direct reason. A block arrives as a normal tool result, so the agent can [continue the task without the blocked operation](/guides/how-it-works#what-a-block-looks-like).

CC Safety Net decides by what a command does, not how it is spelled. It allows `git checkout -b feature` because the command creates a branch. It blocks `git checkout -- file` because the command discards uncommitted changes. Both commands start with the same two words.

## Frequently asked questions

### Is CC Safety Net free?

Yes. CC Safety Net is free and MIT licensed. The source is on [GitHub](https://github.com/kenryu42/cc-safety-net).

### Does CC Safety Net use an LLM?

No. A local, rule-based parser makes every decision, and no model is called. The same command gets the same decision every time. See [How it works](/guides/how-it-works#does-cc-safety-net-use-an-llm).

### Does CC Safety Net send my data anywhere?

No. CC Safety Net has no telemetry and makes its decisions locally, with no network calls. It uses the network only when `npx` or `bunx` fetches the package, when `rule add` or `rule update` fetches a rulebook from GitHub, and when `update` checks the npm registry. The [audit log](/reference/audit-log) stays on your machine.

### Does CC Safety Net slow down my agent?

Integrations that load as a plugin inside the agent add little. Hooks that run through `npx` add a few hundred milliseconds per tool call. If yours are slower, see [Troubleshooting](/guides/troubleshooting).

### Does CC Safety Net work on Windows?

Yes, for every agent except Hermes Agent and OpenClaw, which run on macOS and Linux only. Amp documents macOS, Linux, and WSL rather than native Windows. See [Before you install](/installation#before-you-install).

### Is CC Safety Net a sandbox?

No. A sandbox contains the filesystem and network. CC Safety Net blocks destructive operations that a sandbox permits inside your project, so run both. It cannot see inside binaries or check commands that bypass its integration. See the [protection-layers comparison](/guides/vs-sandboxing) and [Known limitations](/guides/known-limitations).
